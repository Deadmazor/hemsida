Programmering

Jag har studerat programmering i flera år, både på gymnasiet och på universitet, så det är självklart att jag har ett stort intresse för det.

Jag har mest erfarenhet med programmeringsspråket C#, men jag har också programmerat mycket Python, och lite grann i Go. Jag påbörjade att ta ett certifikat i C# under gymnasiet, men jag hade tyvärr inte tillräckligt med pengar för att kunna ta alla prov.

Regel nummer 1 för att inte göra en programmerare sur är att aldrig kalla HTML eller CSS för ett programmeringsspråk. Javascript är ett programmeringsspråk, men HTML är ett märkspråk (markup language) och CSS är ett "style sheet language" (finns ingen bra svensk översättning). Skillnaden kanske känns liten, men jag tycker det är viktigt att poängtera den ändå. Jag hittade till exempel bilden för denna sida på Wikimedia Commons när jag sökte på "programming", men det är tekniskt sett både HTML och Javascript med i bilden, så programmeringsnörd som jag är behövde jag nämna att HTML inte är ett programmeringsspråk.
